# Проект: лёгкая версия star-comp.ru

Переносим сайт с Тильды на статичный HTML/CSS. Владелец не программист: общаться по-русски, простыми словами, после каждой правки показывать результат.

## Правила работы

- Править только исходники в `src/` и данные в `content/`, затем запускать `python3 src/build.py`. Файлы `*.html` в корне и нарезанные фото в `assets/` — результат сборки.
- **Каждое изменение сразу коммитить и пушить в GitHub** (`git add -A` → commit → push). Владелец работает с двух компьютеров: всё, что не запушено, для него потеряно. Перед началом работы — `git pull`.
- Страницы сборок собираются из `content/builds/<адрес>.json` (один файл — одна страница); исходные фото каждой сборки — в своей папке `content/photos/<адрес>/`, фото карточек — в `content/photos/cards/`. Эти же файлы правит владелец через админку `admin/` (Sveltia CMS 0.265.1, лежит в репозитории; поля — `admin/config.yml`). Меняешь поля в сборщике — меняй и в `admin/config.yml`.
- После правки проверять в Playwright: нет горизонтальной прокрутки на 320, 390, 768, 1024, 1440, 2560 px.
- Превью для владельца — артефакт https://claude.ai/artifact/BJVhXyESvVyjV1DFkxudaN . Страница артефакта — `.preview/star-comp.html` (создаётся сборщиком), остальные страницы и `assets/` публикуются как файлы рядом.
- Не выдумывать характеристики, цены и тексты: брать со старого сайта или спрашивать.

## Принятые решения

- Две раскладки: мобильная до 1024 px (колонка не шире 576 px, по центру) и десктопная от 1024 px. Планшетной нет — владельцу она не понравилась.
- Страница сборки — одна колонка по центру (решение владельца от 14.11.2026, по образцу Тильды): галерея с точками-переключателями, под ней название, цена, строка рассрочки, текст; вертикальное видео — узкой колонкой по центру, горизонтальное — во всю ширину. Кнопки CTA на страницах сборок нет (владелец убрал «Консультацию» 18.11.2026).
- Шкала шрифтов из четырёх размеров в `:root` (`--fs-h` 30–38px, `--fs-h3` 24px, `--fs-l` 18–20px, `--fs-m` 16px); новых размеров не добавлять, мельче 16 px не делать.
- Шрифт Gilroy, два начертания (400 и 600). Manrope (бесплатная замена, файлы в `assets/`) снята с сайта по решению владельца 17.11.2026 — файлы оставлены, `@font-face` Manrope в `src/page.css` закомментирован из использования, вернуть можно за один шаг (шрифт + `--font` + прелоады в `src/build.py`). Цвета: фон `#0a0a0a`, голубой `#00d9ff`, розовый `#ff28b4`.
- Фото сборок — 4:3, корпус целиком. Форматы AVIF + WebP в нескольких размерах; качество AVIF 80, WebP 95 (владельцу качество видно — ниже не опускаем, решение 17.11.2026), всё ниже первого экрана — `loading="lazy"`.
- Стили и скрипты — внешними файлами `assets/style.css`/`page.js` (главная) и `assets/inner.css`/`inner.js` (страницы сборок); кэшируются между страницами, метка `?v=<дата сборки>` сбрасывает кэш. Значок Сплита — упрощённый `assets/split-logo.svg` (~3 КБ). В `.preview/star-comp.html` всё по-прежнему вшито внутрь (артефакт должен быть самодостаточным).
- Сборщик в конце удаляет из `assets/` файлы, на которые не ссылается ни одна страница (дубли после переименования фото и пр.). Статичные файлы (`favicon.svg`, `icon-192.png`, `og-home.jpg`, шрифты, `split-logo.svg`, файлы стилей/скриптов) чистка не трогает.
- Видео — Kinescope, плеер подгружается только по клику на обложку.
- Адреса страниц, title и якоря меню — как на старом сайте (`seo/urls.csv`). В ссылках внутри проекта пока стоит `.html` ради превью; canonical — без расширения.
- SOLAR S1: верная видеокарта — RTX 5050. Title и description этой страницы владелец разрешил изменить (в адресе остаётся 5060, адрес не трогаем). У блока видео заголовка нет вообще — владелец просил убрать.
- Страница сборки: галерея крупная по центру, под ней блок по ширине фото в две строки — [название | цена], линия, [текст | кнопка] (вариант «C3», выбран владельцем). На телефоне — одной колонкой по центру.
- Эффект наведения на карточки сборок слабый (владелец просил вдвое меньше исходного).
- В карточках сборок под ценой кнопка «Рассрочка от N ₽»: официальный значок Яндекс Сплита (`assets/split-logo.svg`), текст фирменным голубым, подчёркивание сплошное; N = цена ÷ 24 (максимальный срок Яндекс Сплита), округление вверх до сотен. Стрелка-кнопка карточки выровнена по нижней строке (рассрочке) — блок `card__foot-left`. Клик открывает окно «split-info» с краткими условиями (диалог в `src/page.body.html`, стили в `src/page.css`, обработчик в конце `src/page.js`); та же строка стоит и на страницах сборок под ценой (класс `product__split`).
- Комплектующие сборок (`content/builds/*.json`, поле `specs`) — с 18.11.2026 объект `{cpu, gpu, motherboard, ram, storage, psu, cooling, case}` (ключ → значение из «Базы железа»). В админке — восемь отдельных полей-`relation`, у каждого свой фильтр по категории (`filters: [{field: type, values: [...]}]` — Sveltia не умеет динамические фильтры по значению другого поля). Старый формат списка `[{label, value}]` сборщик по-прежнему читает. Порядок строк на сайте фиксированный (`_SPEC_FIELDS` в `src/build.py`).

## Что не доделано

- Перенесены 15 страниц сборок из ~50 (главная частично: первый экран, преимущества, «Популярные конфигурации», отзывы, контакты).
- Форма заявки, счётчики и квиз не подключены.
- Разделы «Компьютеры в наличии», «Обслуживание», «Акции» ещё не перенесены.
- Карточки на главной собираются сборщиком из `content/cards.json` (правятся через админку). Бейджи-фильтры AMD/INTEL **выключены** по решению владельца (17.11.2026, «продолжу с ними работать»): флаг `_FILTERS_ON=False` в `src/build.py`. Код готов: `_cpu_filters` в `src/build.py`, `#cpu-filters` в конце `src/page.js`, стили `.filters` в `src/page.css`; включение — `_FILTERS_ON=True`.
- Админка: кнопка «Дублировать» в коллекции «Страницы сборок» (`admin/duplicate.js`, подключён в `admin/index.html`). Появляется рядом с «Удалить», когда открыт список коллекции; копирует отмеченные галочками страницы через GitHub Contents API (токен — из localStorage `sveltia-cms.user`), к названию добавляет « - копия», к адресу — `-kopiya` (если занят — `-kopiya-2`…), после создания открывает первую копию на редактирование. Кнопка — обычный DOM-скрипт с MutationObserver (у Sveltia нет API для своих кнопок тулбара).
- Админка: защита от дублей в «Базе железа» (`admin/hardware-guard.js`). Sveltia не умеет проверять уникальность значения поля и молча создаёт файл с «-1» — поэтому: (1) красная плашка над редактором, если вводимая модель уже есть (сверка со списком из GitHub); (2) сборщик в начале печатает предупреждение о дублях моделей (`src/build.py`, блок «контроль дублей»). Сайт при дубле не ломается — значения спецификаций это просто строки.
- Админка: защита от дублей папок картинок (`admin/media-guard.js`) — красная плашка в «Ресурсах», если папки дают одно имя без учёта регистра; `src/rename_photos.py` при дубле папок пропускает переименование (чтобы фото не смешались) и пишет предупреждение.
- Блок «Компьютеры в наличии» показывается на главной и в конце каждой страницы сборки (перелинковка + показ готовых PC, решение 18.11.2026). Управляется через админку (`content/stock.json`): ползунок «Скрыть» прячет блок сразу везде. Карточки в админке свёрнуты по умолчанию (`collapsed: true`).
- Ритм зазоров между блоками (решение 18.11.2026): **40 px на мобильном, 60 px на десктопе** между любыми соседними блоками. Схема: у секций симметричные паддинги (мобильный 20+20, десктоп 30+30); на страницах сборок у «О сборке»/«Конфигурации» асимметрия «низ 0, верх = зазор» (40/60), потому что у галереи низ нулевой. Правила: `src/page.css` — `.section`, `.perks`, `.tf-section`, `.tfooter{margin-top:0}`; `src/inner.css` — `.section--about`, `.section--spec`. Замеры всех стыков сделаны в браузере.
- SEO-страница `kupit-kompyuter-spb.html` (18.11.2026): клон главной — собирается из тех же исходников, меняется вместе с ней. Отличается title/description/canonical (адрес `https://star-comp.ru/kupit-kompyuter-spb`) и заголовок H1 — «Купить компьютер с гарантией и запасом на 5 лет» (запрос «купить компьютер…»), чтобы не конкурировать с главной в поиске. Все SEO-тексты страницы — в `src/build.py` (блок «SEO-страница „Купить компьютер в СПб“»); есть в sitemap. Не появляется в меню — ссылку добавит владелец при желании.
- Блок «7 причин заказать у нас» (перенос с Тильды, сделал Клод в ветке, владелец перенёс на сайт 19.11.2026) — на главной после «Компьютеров в наличии». Разметка — в `src/page.body.html` (блок `why`), стили — в `src/page.css`, фото — `content/photos/blocktest/blocktest_1.webp` (нарезка — в `src/build.py`). Тестовая страница blocktest.html осталась (noindex). На мобильном карточки листаются пальцем, фото скрыто; на десктопе фото слева, карточки в две колонки.
