# STAR-COMP — лёгкая версия сайта

Статичная вёрстка сайта star-comp.ru взамен версии на Тильде: чистый HTML и CSS, без библиотек.

## Что где лежит

- `index.html` — главная страница (собирается автоматически, руками не править)
- `solar-s1-intel-core-i5-12400f-nvidia-rtx-5060-8gb.html` — страница сборки SOLAR S1 (тоже собирается)
- `assets/` — шрифты, фото, иконки сайта
- `src/` — исходники: вёрстка, стили, скрипты и сборщик
- `seo/urls.csv` — все адреса старого сайта с заголовками и описаниями; по этой карте переносятся страницы

## Как собрать

```bash
python3 src/build.py
```

Сборщик встраивает стили, логотип и иконки прямо в HTML, чтобы страница открывалась одним запросом.

## Что важно при публикации

- Адреса страниц на хостинге должны быть без `.html` (как на старом сайте), иначе страницы потеряют позиции в поиске.
- Кнопки «Подобрать компьютер» и «Заказать компьютер» пока ведут на якорь-заглушку `#podbor` — форма заявки не подключена.
- Счётчики (Яндекс Метрика, Top.Mail.Ru) и квиз не подключены.
